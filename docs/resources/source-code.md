# Source Code

ASHS, HyperASHS and the tools they build on are open source and developed on GitHub. Use the GitHub issue trackers to report bugs and request features.

## ASHS

| Project | Repository | Description |
|---|---|---|
| HyperASHS | [pyushkevich/HyperResASHS](https://github.com/pyushkevich/HyperResASHS) | The HyperASHS Python package (`hyperresashs`) and the `hrashs` command |
| ASHS Classic | [pyushkevich/ashs](https://github.com/pyushkevich/ashs) | The original ASHS shell scripts and atlas building tools |
| This website | [pyushkevich/ashs-website](https://github.com/pyushkevich/ashs-website) | Documentation source. Corrections and suggestions are welcome as issues or pull requests. |

## Related tools

| Project | Repository | Description |
|---|---|---|
| CRASHS | [pyushkevich/crashs](https://github.com/pyushkevich/crashs) | Surface-based modeling and thickness analysis of ASHS and HyperASHS segmentations |
| ITK-SNAP | [pyushkevich/itksnap](https://github.com/pyushkevich/itksnap) | Image viewer and segmentation tool; client for Cloud ASHS and Cloud HyperASHS |
| Greedy | [pyushkevich/greedy](https://github.com/pyushkevich/greedy) | Fast deformable image registration, used by ASHS and HyperASHS |
| Convert3D | [pyushkevich/c3d](https://github.com/pyushkevich/c3d) | Command-line image processing tool, used by ASHS |
| nnU-Net | [MIC-DKFZ/nnUNet](https://github.com/MIC-DKFZ/nnUNet) | The deep learning segmentation framework underlying HyperASHS |

The pre-trained HyperASHS models and the ASHS Classic atlas packages are hosted on Hugging Face rather than GitHub; see [Models and Atlases](models-and-atlases.md).
