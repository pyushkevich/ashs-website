# Mailing List and Support

To keep up with software updates and to get help with running ASHS or HyperASHS, please join and use the [ashs-users](http://groups.google.com/group/ashs-users) Google group.

To report a bug in HyperASHS, please [open an issue on GitHub](https://github.com/pyushkevich/HyperResASHS/issues).
