# ASHS / HyperASHS website

Source for the ASHS and HyperASHS documentation website, built with [Zensical](https://zensical.org) and published to GitHub Pages at <https://ashs.itksnap.org/> (custom domain; DNS has a CNAME from `ashs.itksnap.org` to `pyushkevich.github.io`).

## Editing

Pages are Markdown files in `docs/`:

- `docs/index.md`: landing page
- `docs/hyperashs/`: HyperASHS documentation
- `docs/ashs/`: ASHS Classic documentation (migrated from the old Google Site)
- `docs/resources/`: citations, related projects and mailing list, shared by both

The navigation is defined in `zensical.toml` (`nav`). Images are in `docs/assets/images/{hyperashs,ashs}/`.

## Preview locally

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/zensical serve
```

Then open <http://localhost:8000/>.

## Publishing

Every push to `main` builds the site and deploys it to GitHub Pages (`.github/workflows/docs.yml`). In the repository settings, Pages must use **GitHub Actions** as its source.

## HyperASHS / ASHS Classic toggle

The switch in the header (`overrides/partials/version-toggle.html`) and the "equivalent page" link at the bottom of each page (`overrides/partials/content.html`) use the `[project.extra.counterparts]` table in `zensical.toml`. It maps each page URL to the parallel page in the other section. Pages that are not listed fall back to the other section's landing page. When you add a page that has a counterpart, add both directions to the table.

Pages under `ashs/` automatically show a banner recommending HyperASHS.

## Look and feel

The site imitates the old Google Site: a dark header with a horizontal menu, and a title banner on every page. This is done with template overrides, not a separate theme:

- `overrides/partials/header.html` and `topnav.html`: the header and the menu. The menu shows Home, the pages of the active version (HyperASHS or ASHS Classic) and Resources, built from `nav`. Sections become dropdowns.
- `overrides/main.html`: the title banner. Pages can set `banner` and `banner_subtitle` in their front matter.
- `docs/assets/css/extra.css`: the colors (`--gs-*`), menu, banner and headings.

Below 1280px wide the menu is replaced by the standard navigation sidebar or drawer.
