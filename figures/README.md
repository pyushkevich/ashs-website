# HyperASHS documentation figures

The HyperASHS figures in `../docs/assets/images/hyperashs` are generated by scripted ITK-SNAP sessions, using
ITK-SNAP's GUI test mode (`ITK-SNAP --test script.js`). This requires an ITK-SNAP
build that includes `engine.screenshot` (4.6.0-alpha.3 or later) and a display.

1. `make_data.sh [for_docs_dir]` prepares the display images in `work/` from the example subject and
   the `hrashs run` outputs (T1+T2 and T1-only). By default these are read from `../../for_docs`
   (next to this repository). This needs `c3d`, `itksnap-wt` and `PYTHON`.
2. `make_figures.sh [figure ...]` renders each figure in its own ITK-SNAP session and writes
   it to `../docs/assets/images/hyperashs`. The figures are listed at the bottom of the script, and each one is
   a set of ITK-SNAP image options plus options for `scripts/fig_view.js`, optionally followed by
   a center crop (`HxW`, done with macOS `sips`).

Environment variables: `SNAP` (the ITK-SNAP executable), `WT` (itksnap-wt), `C3D`,
`PYTHON` (needs SimpleITK and numpy, used for contrast windowing and by `make_camera.py` for 3D viewpoints),
`WORK` and `OUT` (to override the work and output directories).

`work/` holds about 70 MB of intermediate images and is not committed.

Notes:
- ITK-SNAP displays everything in the voxel space of the main image. The hyper-res
  segmentations (~0.4mm) are therefore shown over anatomical images resampled to ~0.4mm.
- ITK-SNAP's default contrast spans the full intensity range, which leaves the MTL nearly black
  in the TSE. `make_data.sh` therefore clips the T2 display images just above the 99.9th
  percentile of the intensities inside the segmentation.
- Appearance changes such as a black 3D background or hidden crosshairs are made through the
  preferences dialog. Preferences are never saved in test mode.
- The 3D world coordinates of ITK-SNAP are RAS. `make_camera.py` frames the labels that have
  the mesh flag set in the label file.
